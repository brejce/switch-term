## 1. 几何（设计像素 1280×720 基准）

- 键 `52×52`，水平 pitch `56`，垂直 pitch `58`
- 左场原点 `(24, 400)`，行错位 `0 / +10 / +20`（往下向掌心收）
- 右场原点 `(980, 400)`，行错位 `0 / −10 / −20`（镜像）
- 中间终端：`x 320..960`，8px 字宽 → **80 列**
- 物理场原点：左 = `d`，右 = `k`（两个摇杆零位各对自己那一半的中心）

## 2. 三层字符表

层序循环：`ALPHA → NUM → SYM → ALPHA`（L3 每按一次前进一层）。

### ALPHA（字母层）

```
左手                          右手
q  w  e  r  t                 y  u  i  o  p
a  s  d  f  g                 h  j  k  l  :
z  x  c  v  ,                 b  n  m  .  ?
```

### NUM（数字层）— 高频标点靠近各自中心

```
左手（d 中心 = .）            右手（j 中心 = :）
1  2  3  4  5                 6  7  8  9  0
[  -  .  |  /                 )  :  ;  >  <
]  =  _  ,  (                 "  '  ~  ?  @
```

### SYM（符号层）— 剩余标点 + 高频重复

```
左手                          右手
!  @  #  $  %                 ^  (  )  _  "
{  }  [  ]  \                 `  '  ,  .  ?
&  *  +  ;  ~                 -  /  |  =  <
```

32 个 ASCII 标点全覆盖，逐条核对：
`! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { | } ~`

### Shift（只作用于字母）

- 字母层：`q` → `Q`，sticky 一次 / 双击锁定，**中文态下同样直出大写，不进拼音组字**
- NUM / SYM 层：Shift 无意义（保留按键，不产生上档字符）

## 3. 键帽双面

每个键位同时显示两个字符：**主字符**（当前层，大、亮）+ **副字符**（下一层，小、淡，画在主字符下方）。

| 当前层 | 主 | 副 |
|---|---|---|
| ALPHA | `q` | NUM 层同位置的 `1` |
| NUM | `1` | SYM 层同位置的 `!` |
| SYM | `!` | ALPHA 层同位置的 `q` |

层切换 = 主副互换 + 字号/颜色翻转，**位置不动**，所以物理场手感跨层一致。

## 4. 物理（两个独立的场）

每侧一个 `Pointer` 实例，同一份参数：

| 事件 | 含义 |
|---|---|
| `hover_changed` | 指针当前最近的键变了（无吸附时） |
| `snap` | 进入某键的 `snap_radius` → 高亮 + 震动 |
| `release` | 反向推力超过 `release_power` → 脱开 |

参数进 `engine.lua` 的 `physics` 段（见 §6）。**吸附只高亮，不上屏。**
（纯映射层不带时间与重复逻辑，`repeat_*` 这类参数放 app 层，见 `ARCH.md` §5.4。）

## 5. 按键分工（不含摇杆移动）

| 输入 | 动作 |
|---|---|
| 左摇杆 | 左手区 15 键的物理指针（原点 `d`） |
| 右摇杆 | 右手区 15 键的物理指针（原点 `j`） |
| **LB（L）** | 上屏**活跃侧**当前 `snap` 的字符；`hover` 只做弱高亮，**永不上屏**；无 snap 则不动作 |
| **L3（摇杆按下）** | 层循环 ALPHA→NUM→SYM |
| **A / B / X / Y** | 回车 / 退格 / Delete / Esc。面板按真机摆位：**X 上、Y 左、A 右、B 下** |
| **R / ZR** | 光标左 / 右（`ESC[D` / `ESC[C`）；带 Shift（单击 sticky 一次 / 双击锁定）变上 / 下（`ESC[A` / `ESC[B`）——手柄没别的键发上下箭头 |
| **组字出候选时** | R / ZR 不光标，而是在候选条里移动选中项（候选优先级最高） |
| **Tab 窗口内的 R / ZR** | 上一个 / 下一个终端 tab，循环；**至少 2 个 tab 才生效**（只有 1 个时退化为光标）。<br>窗口 = DPAD_UP 之后 1.2s，且**每按一次顺延**，所以按住 Tab 连按能一直翻；<br>做任何其它动作立刻关窗口（设备只报按下不报松开，所以用时间窗近似「按住」） |
| **ZL（LT）** | 空格；**组字中 = 上屏当前选中的候选** |
| **＋（PLUS）** | `onboard`：拉起屏幕键盘（桌面模式下 KDE 抢先时的兜底） |
| **⭕（CAPTURE）** | 待定 |
| **🏠（HOME）** | 待定 |
| DPAD 左 / 右 / 下 / 上 | 一次性 **Shift / Alt / Ctrl / Tab**，双击锁定（锁定的会在左面板点亮）。<br>位置与面板上画的图一致：左 Shift、右 Alt、下 Ctrl、上 Tab |
| DPAD_DOWN + ZL（Ctrl+空格） | 切中英（等价键盘 `Ctrl+Space`）；组字中的拼音原样落下 |
| L3 键码备注 | `BTN_THUMBL(318)`；`BTN_THUMBR(319)` 在设备上不存在 |

## 6. 物理参数（`config/engine.lua`）

**参数只有一处真相：`config/engine.lua` 的 `engine.physics`。** 本文不再抄一份（抄过，已经漂了：
文档写 `damping 0.88 / attract_power 2.4`，代码里是 `0.35 / 60`）。看现值：

```fish
grep -A 14 "engine.physics" config/engine.lua
./build/switch-ime-term --audit-physics   # 零位/推进/穿越速度/回落/脱开 + 确定性
```

只在文档里固定「不打算当旋钮」的东西：

- `dt` **写死在 C++（1/60）**，不进配置——同一输入序列要能确定性回放。
- 左右两个场完全独立，共用同一套 30 键局部坐标；`home` 各是一个键（左 `d` / 右 `j` 附近）。
- 吸附与脱开是**两套阈值**（进得快、出得黏），高亮半径 ≠ 吸附半径。
- 摇杆死区在**进物理场之前**滤（`engine.input.deadzone`），否则松手回不到零位。
