## 1. 几何（设计像素 1280×720 基准）

- 键 `52×52`，水平 pitch `56`，垂直 pitch `58`
- 左场原点 `(24, 400)`，行错位 `0 / +10 / +20`（往下向掌心收）
- 右场原点 `(980, 400)`，行错位 `0 / −10 / −20`（镜像）
- 中间终端：`x 320..960`，8px 字宽 → **80 列**
- 物理场原点：左 = `d`，右 = `k`（两个摇杆零位各对自己那一半的中心）

## 2. 三层字符表

层序循环：`ALPHA → NUM → SYM → ALPHA`（L3 每按一次前进一层）。

### ALPHA（字母层）

```
左手                          右手
q  w  e  r  t                 y  u  i  o  p
a  s  d  f  g                 h  j  k  l  :
z  x  c  v  ,                 b  n  m  .  ?
```

### NUM（数字层）— 高频标点靠近各自中心

```
左手（d 中心 = .）            右手（j 中心 = :）
1  2  3  4  5                 6  7  8  9  0
[  -  .  |  /                 )  :  ;  >  <
]  =  _  ,  (                 "  '  ~  ?  @
```

### SYM（符号层）— 剩余标点 + 高频重复

```
左手                          右手
!  @  #  $  %                 ^  (  )  _  "
{  }  [  ]  \                 `  '  ,  .  ?
&  *  +  ;  ~                 -  /  |  =  <
```

32 个 ASCII 标点全覆盖，逐条核对：
`! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { | } ~`

### Shift（只作用于字母）

- 字母层：`q` → `Q`，sticky 一次 / 双击锁定，**中文态下同样直出大写，不进拼音组字**
- NUM / SYM 层：Shift 无意义（保留按键，不产生上档字符）

## 3. 键帽双面

每个键位同时显示两个字符：**主字符**（当前层，大、亮）+ **副字符**（下一层，小、淡，画在主字符下方）。

| 当前层 | 主 | 副 |
|---|---|---|
| ALPHA | `q` | NUM 层同位置的 `1` |
| NUM | `1` | SYM 层同位置的 `!` |
| SYM | `!` | ALPHA 层同位置的 `q` |

层切换 = 主副互换 + 字号/颜色翻转，**位置不动**，所以物理场手感跨层一致。

## 4. 物理（两个独立的场）

每侧一个 `Pointer` 实例，同一份参数：

| 事件 | 含义 |
|---|---|
| `hover_changed` | 指针当前最近的键变了（无吸附时） |
| `snap` | 进入某键的 `snap_radius` → 高亮 + 震动 |
| `release` | 反向推力超过 `release_power` → 脱开 |

参数进 `engine.lua` 的 `physics` 段（见 §6）。**吸附只高亮，不上屏。**
（纯映射层不带时间与重复逻辑，`repeat_*` 这类参数放 app 层，见 `ARCH.md` §5.4。）

## 5. 按键分工（不含摇杆移动）

| 输入 | 动作 |
|---|---|
| 左摇杆 | 左手区 15 键的物理指针（原点 `d`） |
| 右摇杆 | 右手区 15 键的物理指针（原点 `j`） |
| **LB（L）** | 上屏**活跃侧**当前 `snap` 的字符；`hover` 只做弱高亮，**永不上屏**；无 snap 则不动作 |
| **L3（摇杆按下）** | 层循环 ALPHA→NUM→SYM；双击锁层 |
| **A / B / X / Y** | 回车 / 退格 / Delete / Esc |
| **R / ZR** | 光标右 / 左（`ESC[C` / `ESC[D`）；锁 Shift 时扩选 |
| **ZL（LT）** | 空格 |
| **RB（R）** | 保留（原鼠标左键），暂无用途 |
| **−（MINUS）** | 待定 |
| **＋（PLUS）** | 待定 |
| **⭕（CAPTURE）** | 待定 |
| **🏠（HOME）** | 待定 |
| DPAD ←/→/↓/↑ | 一次性 Ctrl / Shift / Alt / Tab，双击锁定 |
| L3 键码备注 | `BTN_THUMBL(318)`；`BTN_THUMBR(319)` 在设备上不存在 |

## 6. 物理参数（`config/engine.lua`）

```lua
engine.physics = {
    dt            = 1/60,  -- 固定步长，无随机，可离线回放
    damping       = 0.88,  -- 松手滑行衰减
    attract_power = 2.4,   -- 引力，随距离衰减
    snap_radius   = 18,    -- 进入即吸附（只高亮）
    release_power = 1.8,   -- 反向推力超过才脱开
    max_speed      = 800,  -- px/s，推到底最快
    speed_slow_end = 0.5,  -- 推杆 5/10 之前是微操段
    speed_low      = 0.3,  -- 微操段顶端速度（× max_speed）
    hover_radius  = 26,    -- 无吸附时的最近键判定
}
```
