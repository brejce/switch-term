## 1. 几何（设计像素 1280×720 基准）

> 数值唯一的真相是 `config/ui.lua`；下表是那里当前的值，改配置就改这里。

- 键帽 `48×48`（`ui.key_size`），局部坐标 `c*58, r*62`（水平间隙 10、垂直间隙 14）
- 世界 = 每手 **5 列 × 4 行 = 20 键**（两手共 40）；坐标是**局部**的，左右手各一个独立的场，
  屏上位置由 `keyWindowRect()` 算：窗口在面板里居中，再整体上移 `ui.key_area_dy = −100`
- 窗口（一屏露多少）= **`ui.key_window = {cols=3, rows=4}`** = `2*58+48 = 164` 宽 × `3*62+48 = 234` 高，
  塞进 `panel_w 176`
- 纵向世界 4 行 = 窗口 4 行 → **一次全露、纵向不滚**（数字行常驻可见）；
  横向世界 5 列只露 3 列，外层 2 列靠相机平移进来（相机不夹取，见 §3.5）
- 面板 `176` / 顶栏 `32` / 底栏 `26` → 内容区 `662`
- 中间终端：`x 176..1104`（宽 `928`），字符格 `8×21`，留白左右 `14` / 上 `10` / 下 `8`
  → **112 列 × 28 行**网格，下面再留 2 行（`ui.ime_rows`）给组字串 + 候选，这 2 行不占 PTY 行数
- 物理场原点：左 = `d`（全局下标 12），右 = `k`（全局下标 32）——两个摇杆零位各对自己那一半的掌心键

> 设计稿 `design/v3-terminal.html` 的 176 / 键 48 已经落地（不再是要先重调物理的提案）。

## 2. 两层字符表

层序循环：`ALPHA ⇄ NUM`（L3 每按一次换一层，`kLayerCount = 2`）。

### ALPHA（主键区 = 真实键盘的数字行 + 三行字母）

```
左手                          右手
1  2  3  4  5                 6  7  8  9  0
q  w  e  r  t                 y  u  i  o  p
a  s  d  f  g                 h  j  k  l  ;
z  x  c  v  b                 n  m  ,  .  /
```

### NUM（主键区放不下的标点）— 都贴着 home 行，切过去就看得见

```
左手                          右手（真实键盘右上那排 ` - = [ ] \ '）
·  ·  ·  ·  ·                 ·  ·  ·  ·  ·
·  ·  ·  ·  ·                 `  -  =  [  ~
·  、 【 】 ·                 ·  ]  \  '  ·
·  「 」 ·  ·                 ·  ·  ·  ·  ·
```

`·` = 该位置在这一层是**空键**（`ui.layers.num` 里是空串）：不画，也不参与引力/吸附/边界。

### Shift（上档字符 = `ui.shifts`）

- 每个键的副字符就是它在当前层的上档；**没上档的键不画副字符**（字母不列：标签本身已是大写）。
- ALPHA 字母：英文态 Shift → 大写；中文态按小写进拼音组字（`ime_route.cpp`，锁了 Shift 也不会
  把拼音打成大写）。
- ALPHA 数字行：`1→! 2→@ 3→# 4→$ 5→%` / `6→^ 7→& 8→* 9→( 0→)`，与真实键盘一致。
- ALPHA 标点：`;→:` `,→<` `.→>` `/→?`
- NUM：`` ` `` 无上档；`-→_ =→+ [→{` / `]→} \→| '→"`。
- 该键没有上档时 Shift 不产生额外的字，退回下档（`app.cpp` 的 `kMagic`）。

## 3. 键帽双面

每个键位最多显示两个字符：**主字符**（当前层 `ui.layers`，大、亮）+ **副字符**（该层的上档
`ui.shifts`，小、淡，画在主字符下方）。没有上档的键只画主字符，也不给副字符留位置
（留了位置会把主字符顶高）。

| 当前层 | 主 | 副 |
|---|---|---|
| ALPHA 字母 | `q`（标签画大写 `Q`） | 无 |
| ALPHA 数字行 | `1` | `!` |
| NUM 左手标点 | `、` | 无 |
| NUM 右手符号 | `-` | `_` |

换层 = 同一个键位换一组字符，**位置不动**，所以物理场手感跨层一致。

## 3.5 遮罩与相机（渲染侧）

**相机**（`app.cpp` 的主循环，每侧一个）：目标 = 吸附键中心 + `0.30 × (指针 − 键心)` 的一点视差，
用欠阻尼弹簧跟过去（`ω=34, ζ=0.45`，约 0.15s 到位、过冲 ~18%）。视差是为了不让画布“一档一档整格跳”；
指针被引力收进键心后这一项自然归零。

- **不夹取**：选中的键永远钉在面板准心上，滚到最外圈时那一侧就是留白，这里接受。
- 没吸附时贴**最近的高亮键**；连高亮都没有（指针停在分层空槽里）→ **原地不动**，绝不对准空白。
- 键窗裁剪按键帽 `0.6` 倍外扩再与面板求交，所以相机过冲时最外圈的描边不会被窗口边界横切一条。

**径向遮罩**（`screen.cpp` 的 `vignette`）：以准心为圆心铺满整个面板，
遮盖强度 = `1 − exp(−d/τ)`，`τ = 1.5`，`d` 按「**格**」算（横向一格 = 纵向一格 = 键距，
横向 58px、纵向 62px 等权）。指数衰减：中心掉得快、外圈拖长尾——

| 距离 | 遮盖 |
|---|---|
| 中心（d=0） | 0 |
| 邻键（d=1） | 49% |
| 数字行 / 隔一行（d=2） | 74% |
| 对角邻键（d≈2.2） | 77% |

遮罩色 = 面板底色往黑压 10%，按 2px 小格填充（远场接近饱和处改 10px 大块铺，省绘制调用）。
同一套「格」距离还决定外围键缩小：`0.6` 格开始缩、`2.3` 格缩到最小（−30%）；
`exp(−d/τ) ≤ 0.04`（约 4.8 格）的键整块不画。

**面板底部提示表**（`screen.cpp` 的 `kLeftHints` / `kRightHints`，两列右/左对齐 + 一条 1px 分隔线）：

| 左面板 | 功能 |
|---|---|
| L | 魔法键 |
| ZL | 空格 |
| L3 | 切层 |
| DPAD | 修饰 |
| 双击DPAD | 锁定 |

| 右面板 | 功能 |
|---|---|
| A | 回车 |
| B | 退格 |
| X | Del |
| Y | Esc |
| R/ZR | 光标←→（有 Shift 修饰时变 `光标↑↓`） |

表里只有 `config/keymap.lua` 真有的绑定（键名按 Switch 的叫法写：`L`/`ZL`/`R`/`ZR`，
`keymap.lua` 里叫 `LB`/`LT`/`RB`/`RT`）；表内容写死在 `screen.cpp`，改键位要一起改。
右面板有两张表：`kRightHints` 与 `st.modShift` 时的 `kRightHintsShift`（右肩键变上/下）。
面板顶部还有一行肩键提示：`L 魔法键` / `ZL 空格`（左）、`R 左` / `ZR 右`（右；有 Shift 修饰时变 `上` / `下`）。

## 4. 物理（两个独立的场）

每侧一个 `Pointer` 实例，同一份参数：

| 事件 | 含义 |
|---|---|
| `hover_changed` | 指针当前最近的键变了（无吸附时） |
| `snap` | 进入某键的吸附半径（`snap_radius + pointer_radius` ≈ 55px）→ 高亮 + 震动 |
| `release` | 离吸附键超过 `snap_radius × release_ratio + pointer_radius`（≈ 65px）→ 脱开；这个距离内更近的键胜出就直接换键 |

参数进 `engine.lua` 的 `physics` 段（见 §6）。**吸附只高亮，不上屏。**
（纯映射层不带时间与重复逻辑，`repeat_*` 这类参数放 app 层，见 `ARCH.md` §5.4。）

## 5. 按键分工（不含摇杆移动）

| 输入 | 动作 |
|---|---|
| 左摇杆 | 左手区 20 键的物理指针（原点 `d`） |
| 右摇杆 | 右手区 20 键的物理指针（原点 `k`） |
| **LB（L）** | 上屏**活跃侧**当前 `snap` 的字符；`hover` 只做弱高亮，**永不上屏**；无 snap 则不动作 |
| **L3（摇杆按下）** | 层循环 `ALPHA ⇄ NUM`（两层） |
| **A / B / X / Y** | 回车 / 退格 / Delete / Esc。面板按真机摆位：**X 上、Y 左、A 右、B 下** |
| **R / ZR（RB / RT）** | 光标左 / 右（`ESC[D` / `ESC[C`）；带 Shift（单击 sticky 一次 / 双击锁定）变上 / 下（`ESC[A` / `ESC[B`）——手柄没别的键发上下箭头 |
| **组字出候选时** | R / ZR 不光标，而是在候选条里移动选中项（候选优先级最高） |
| **Tab 窗口内的 R / ZR** | 上一个 / 下一个终端 tab，循环；**至少 2 个 tab 才生效**（只有 1 个时退化为光标）。<br>窗口 = DPAD_UP 之后 1.2s，且**每按一次顺延**，所以按住 Tab 连按能一直翻；<br>做任何其它动作立刻关窗口（设备只报按下不报松开，所以用时间窗近似「按住」） |
| **ZL（LT）** | 空格；**组字中 = 上屏当前选中的候选** |
| **＋（PLUS）** | `onboard`：拉起屏幕键盘（桌面模式下 KDE 抢先时的兜底） |
| **⭕（CAPTURE）** | 待定 |
| **🏠（HOME）** | 待定 |
| DPAD 左 / 右 / 下 / 上 | **Shift / Alt / Ctrl / Tab**：单击粘一次、按住期间持续生效、双击锁定（锁定的会在左面板点亮）。<br>位置与面板上画的图一致：左 Shift、右 Alt、下 Ctrl、上 Tab |
| DPAD_DOWN + ZL（Ctrl+空格） | 切中英（等价键盘 `Ctrl+Space`）；组字中的拼音原样落下 |
| L3 键码备注 | `BTN_THUMBL(318)`；`BTN_THUMBR(319)` 在设备上不存在 |

## 6. 物理参数（`config/engine.lua`）

**参数只有一处真相：`config/engine.lua` 的 `engine.physics`。** 本文不再抄一份（抄过，已经漂过；
现值看 `docs/PHYSICS.md` §4）。看现值：

```fish
grep -A 24 "engine.physics" config/engine.lua
./build/switch-ime-term --audit-physics   # 零位/推进/穿越速度/回落/脱开 + 确定性
```

只在文档里固定「不打算当旋钮」的东西：

- `dt` **写死在 C++（1/60）**，不进配置——同一输入序列要能确定性回放。
- 左右两个场完全独立，共用同一套 20 键局部坐标；`home` 各是一个键（左 `d` / 右 `k`）。
- 吸附与脱开是**两套阈值**（进得快、出得黏），高亮半径 ≠ 吸附半径。
- 摇杆死区在**进物理场之前**滤（`engine.input.deadzone`），否则松手回不到零位。
