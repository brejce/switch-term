## 一、 项目概述与基调

*   **来源**：《world.execute(me);》的赛博朋克意境——一台只服从指令的机器终端。
*   **本项目的主体不是"被困住的心脏"，而是"掌机上的键盘"**：用户手里握着双摇杆，
    屏幕上没有按钮控件，只有**字符**。机器不解释自己，只回显结果。
*   **基调**：极简、冰冷、机械、程序化、绝对服从。拒绝圆角、卡片、阴影、图标。
*   **交互隐喻**：摇杆推的是**指针**，指针被键的引力吸住 → 反色块 = "这颗键就是你选的"。
    按键即输入，不弹窗、不确认、不庆祝。
*   **色彩态度**：来稿是单色因为硬件单色。这里是 LCD（32bpp fbdev），
    **颜色只用来带语义，不用来装饰**——同一个意思永远同一个颜色，没有渐变、没有发光。

## 二、 硬件与屏幕约束（替换来稿的墨水屏一节）

*   **设备**：Nintendo Switch（switchroot Ubuntu noble，kernel 4.9 l4t）。
*   **面板**：720×1280 竖装，`rotate=270` 后逻辑分辨率 **1280×720 横屏**。
*   **出图**：只有 fbdev `/dev/fb0`（720×1280，stride 2880，32bpp）+ `/dev/tegra_dc_*`；
    没有 `/dev/dri`、没有 KMS/Wayland 合成器。所以 UI 全部自己画，没有窗口系统兜底。
*   **刷新**：60fps 预算 16.6ms，**只重绘脏矩形**；禁止全屏重画。
    来稿里"1 秒批量刷新 + 230ms 闪烁 + 走纸截断"是墨水屏物理特性，这里**一律不要**。
*   **反馈延迟**：吸附/按键高亮 ≤ 120ms 内可见；光标闪烁用 1.1s steps 硬切，不做补间动画。
*   **输入**：Joy-Con（左右可合体）、十字键、ABXY、肩键 L/R/ZL/ZR、HD rumble。
    触摸屏坐标是 720×1280，用之前必须映射到 1280×720 逻辑坐标。
*   **色彩**：LCD 全彩 → 允许 8 种语义色（见 §三），但**同屏实心色块最多 2 个**
    （吸附键 + 模式 chip），其余全是字。

## 三、 视觉规范

### 3.1 颜色（语义唯一，不许乱用）

| 令牌 | `switch` 值 | 用在哪 | 语义 |
|---|---|---|---|
| `kBg` / `kPanel` / `kTerm` | `#05070c` / `#151a24` / `#0b0f16` | 顶/底栏、面板、终端 | 底 → 面板（凸）→ 终端（凹），结构靠明度分层 |
| `kLine` | `#3e4756` | 1px 分隔线 | 只画区带：顶栏下 / 面板竖边 / 候选区上 |
| `kText` / `kDim` / `kFaint` | `#ccd2dc` / `#8891a1` / `#5a6272` | 主文 / 次文 / 装饰 | 三级信息量 |
| `kCyan` | `#46c5d3` | 左手、活动 tab、ALPHA 层、锁定修饰 | 唯一主强调色 |
| `kRed` | `#e87e66` | 右手 | 右手标识、A 键 |
| `kBlue` | `#5f9fd0` | 组字下划线、候选选中、选区、滚动条 | 光标/焦点 |
| `kYellow` | `#d9ab5c` | `MODS`、`ZH` 态、NUM 层 | 修饰与数字层 |
| `kPurple` / `kGreen` | `#a78bea` / `#5cc98f` | SYM 层 / 电量、成功 | 状态色 |

> 值只在 `src/theme/palette.cpp`（另有 `light` / `gruvbox` 主题）。本文与 `UI_DESIGN.md` §二
> 抄的是默认 `switch`；换主题不改语义，也不改调用点（一律 `col::kXxx`）。

### 3.2 字体

全系统 `Maple Mono NF CN`（ASCII 等宽、汉字正好 2 格 → 1:2 字符网格成立），
缺字回落 `Noto Sans CJK SC`。所有坐标按**字符格**算，不按像素拍。

### 3.3 形状

全直角。没有 CSS 式边框、没有背景卡片、没有圆角、没有阴影。
"实心块"只有两种用途：**吸附键（反色）** 与 **模式 chip**。分隔线是唯一允许的线。

## 四、 布局（1280×720）

```
┌──────────────────────────────────────────────────────────────┐  32 顶栏：brand / tabs / 时间 / 电量
├──────────┬────────────────────────────────────┬──────────────┤
│ 220 左   │ 终端 840（101 列 × 28 行）           │ 220 右       │
│ head     │   历史行（可滚动，右侧指示条）     │ head         │
│ 键区3×4  │                                    │ 键区3×4      │
│ dpad十字 │ ── 分隔线 ──                       │ ABXY 十字    │
│ ──────── │   输入行（组字 + 光标）            │ ────────     │
│ 提示 footer│  候选行（固定预留高度）          │ 提示 footer  │
├──────────┴────────────────────────────────────┴──────────────┤  26 底栏：层 / IME / tabs / MODS / 版本
```

面板内的竖向节奏（左右对称，都是"上部密、底部锚定"）：

1. `phead`：`left | L3 · 3×4`，活跃侧的名字用该手语义色（青/珊瑚）。
2. `shoulders`：`L 上屏` / `ZL 空格`，键名用该手语义色。
3. `pad`：3 列 × 4 行滑窗键，**只有字**，离指针越远越暗、越小。
4. `cluster`：dpad / ABXY 画成**真十字**（中心一个 5px 语义色圆点定形），
   不是一堆散字——靠十字形状认方向，不靠提示文字。
5. `hints`：用 1px 分隔线与上面隔开，`键 | 功能` 两列右对齐锚在面板底部。
   **禁止**把提示塞进十字键的行间（会互相压字），也禁止一条提示里堆三件事。

终端区：

*   历史行 `overflow:hidden`，右侧 3px 指示条（蓝，透明度 .5）表示位置，`↕` 表示可触摸滑动。
*   输入行与候选行属于 `composer`，**高度固定预留**：命令行行数涨到最底也不会把候选区挤掉。
*   候选行紧贴输入行下方（跟着光标走），不悬浮、不弹窗、不盖住历史。

## 五、 交互映射（把来稿的"EXECUTE 按钮"换成本项目的真实按键）

*   **左/右摇杆**：各驱动一个指针在 3 列 × 4 行窗口里按引力场运动；离键心够近就吸附，
    整键反色（**唯一实心块**）。滑动时选中的键连续跟随，不闪。
*   **L3**：层循环 `ALPHA → NUM → SYM`；层色进模式 chip 与反色块底色。
*   **LB**：上屏活跃侧吸附的字符（Shift 取上档）；**LT**：空格（不动组字串）。
*   **十字键 = 修饰符**：上 `Tab`（候选翻页）/ 左 `Ctrl` / 下 `Alt` / 右 `Shift`，
    双击锁定，锁定态只在提示区加一条底边线，不做色块。
*   **ABXY**：`A` 回车 · `B` 退格 · `X` Del · `Y` Esc。
*   **RB/RT**：鼠标左右键（走 `/dev/uinput`），**R/ZR**：空格 / 光标左右。
*   **触摸**：上下滑 = 滚动历史（带指示条），点左右半屏 = 光标移动；点候选 = 选词。
*   **震动**：吸附时一次短 rumble；自动回中不震。
*   **tab**：终端里敲 `term`/`quit` 走 OSC 1337 控制序列切 tab，不分配按键。

## 六、 状态机（来稿三状态 → 本项目的六状态）

| 状态 | 屏幕表现 |
|---|---|
| 待机（无输入） | 历史 + 输入行 + 暗键区；底部 `ALPHA / IME 拼音` |
| 输入中 | 吸附键反色，其余键按距离衰减；候选行出现 |
| 组字中 | 组字串蓝下划线 + 光标闪烁；候选行 7 项 + `1/3` 页码 |
| 上屏 | 候选消失，输入行推进；无动画 |
| 错误 | 历史里一行红色 `✗ …`，不弹窗、不遮屏 |
| 断连 | 全部历史变为次级灰，输入行变红 `process exited`，`A` 重启 shell |

来稿的"END OF LINE / TAP TO REBOOT"在本项目**没有对应场景**（这里不是一次性的艺术装置），
不要为了致敬而在 UI 上写 `world.execute(me);` 之类的招牌文字。

## 七、 来稿逐条取舍

| 来稿条目 | 处理 |
|---|---|
| 540×960 竖屏、单色、无抗锯齿 | **改** → 1280×720 横屏，8 种语义色，有抗锯齿 |
| 230ms 局部刷新闪烁、走纸 60px/s、波形截断续画 | **删** → 墨水屏物理特性，本项目只留"只重画画脏的那块" |
| 1px 交叉像素栅格纹理 | **删** → 那是为掩盖墨水屏颗粒；LCD 上会变成脏噪点 |
| 心电图 / 心率引擎 / 早搏 | **删** → 换成分区键区与组字状态 |
| 顶部 SYS.WORLD / 时间 / 电量 | **留** → brand `sit/0.1` / tabs / 时钟 / BAT |
| 底部黑底白字大按钮 EXECUTE | **删** → 输入是被游戏手柄驱动的字符，没有"执行按钮" |
| 全等宽、全直角、硬 1px 线 | **留** → 项目现有字符网格原则 |
| 三种状态（待机/执行/终局） | **改** → 六状态（见 §六），去掉"终局" |
| 对话式文案 `> AWAITING COMMAND_` | **改** → 提示只写 `键 | 功能`，不写叙事台词 |

## 八、 给 AI Agent 的 Prompt 模板

> 生成一份 **1280×720 横屏 LCD** 的 switch-ime-term 界面（HTML+CSS+JS 单文件，评审用）。
>
> **视觉**：`#0a0b0c` 深底 + `#070809` 终端底，全等宽字体，全直角，无边框卡片、无圆角、无阴影。
> 8 种语义色（青左 / 珊瑚右 / 蓝光标 / 琥珀数字层 / 紫注音 / 绿成功 / 红错误），
> 颜色只表达含义；同屏实心块最多 2 个（吸附键 + 模式 chip）。
>
> **布局**：32px 顶栏 / 220px 左面板 / 终端 840（101 列 × 28 行，底部 2 行留给候选）/
> 220px 右面板 / 26px 底栏。
> 面板内：head → 肩键 → 3×4 键区（只有字，按距离衰减）→ dpad/ABXY **真十字**（中心语义色圆点）
> → 提示区用 1px 分隔线隔开、`键 | 功能` 两列锚在底部。
> 终端：历史行 + 右侧 3px 滚动指示条 + 固定高度预留的"输入行 + 候选行"。
>
> **必做**：吸附键是唯一反色块；候选行紧贴输入行（跟光标）且高度固定预留；
> 底栏 `lang` 与 `ime` **合并成一个 `IME 拼音 / 英文·直通` 字段**；提示文字不压键位、
> 一行只说一件事。默认工作目录是登录用户 `~`，提示符写 `~` 不写绝对路径。
>
> **禁止**：墨水屏刷新模拟、扫描线/栅格噪声、渐变发光、漂浮弹窗、
> `world.execute(me);` 招牌文字、任何圆角与阴影。
